# Rainfall Intelligence India 🌧️

## Project Overview
Rainfall Intelligence India is an end-to-end data analytics project focused on analysing rainfall patterns across India using three different datasets.

The project explores daily, historical, and district-wise rainfall information to understand rainfall distribution, seasonal trends, regional variations, and rainfall categories through interactive Power BI report pages.

## Project Objectives
- Analyse rainfall patterns across different regions of India.
- Understand monthly and seasonal rainfall trends.
- Explore district-wise and state-wise rainfall distribution.
- Compare actual rainfall with normal rainfall.
- Identify rainfall variations and patterns through data visualisation.

## Tools & Technologies
- **Excel** – Data inspection and preparation.
- **Python** – Data cleaning and analysis using Pandas and NumPy.
- **Jupyter Notebook** – Python-based analysis.
- **SQL** – Data querying and analysis.
- **Power BI** – Interactive dashboards and visualisation.

## Datasets
This project uses three rainfall datasets:
1. Daily and district-wise rainfall data.
2. Historical rainfall data.
3. District-wise rainfall normal data.

Both original and cleaned datasets were used during the data preparation and analysis process.

## Power BI Dashboards

The project contains one Power BI report file with three report pages:

1. **Daily Rainfall Overview** – Highlights rainfall distribution and key rainfall indicators.
2. **Historical Rainfall Intelligence** – Explores historical rainfall trends, seasonal patterns, and yearly variations.
3. **District Rainfall Normal Intelligence** – Analyses district-wise rainfall, rainfall categories, and actual versus normal rainfall patterns.

## Project Workflow
1. Data Collection
2. Data Inspection and Cleaning
3. Exploratory Data Analysis
4. SQL Analysis
5. Power BI Dashboard Development
6. Insights and Interpretation

## Key Learning Outcomes
- Practical experience in data cleaning and preprocessing.
- Working with multiple datasets.
- Performing data analysis using Python and SQL.
- Creating interactive Power BI reports.
- Understanding rainfall trends and regional variations.

## Project Limitations
- Findings depend on the coverage and quality of the available datasets.
- Missing values and differences in data periods may affect comparisons.
- Rainfall patterns alone cannot establish causes of floods, droughts, or water scarcity.
